## Giới thiệu Dự án: Hệ thống Quản lý Học tập Thông minh

#### 1. Tổng quan
Dự án được xây dựng nhằm hỗ trợ sinh viên quản lý thời gian học tập, theo dõi tiến độ bài tập và kết nối với các thành viên trong nhóm một cách hiệu quả.

#### 2. Tính năng chính
* **Quản lý nhiệm vụ:** Phân công công việc rõ ràng cho từng thành viên.
* **Lịch trình thông minh:** Nhắc nhở deadline tự động.
* **Tài liệu trực tuyến:** Chia sẻ tài liệu nhanh chóng qua GitHub.

#### 3. Công nghệ sử dụng
* **Frontend:** ReactJS, Tailwind CSS
* **Backend:** Node.js, Express
* **Database:** MongoDB
